Integration

ONNA connects the MICA alongside the rest of its ecosystem's manufacturers via KNX and its own API integrations, giving full control over the installation from a single app. That flexibility makes it possible, for example, to make climate control or window opening conditional on the MICA's ventilation index without leaving that same screen.

Company

ONNA

ONNA is a manufacturer of home and building automation hardware and software (touch panels, servers, room controllers, and a mobile app) based on KNX technology, which it complements with API integrations with other manufacturers to combine the best of each ecosystem in a single app. It targets residential projects, hospitality, and commercial buildings.
